# Komponen Penilaian Project Akhir:

## 1. Perancangan Database (30% dari nilai project)
     1. Kesesuaian ERD dengan kebutuhan sistem (10%)
     2. Implementasi normalisasi database (10%)
     3. Optimasi struktur tabel dan relasi (10%)

## 2. Implementasi Sistem (40% dari nilai project)
    1. Implementasi SQL (DDL, DML, DCL) (15%)
    2. Konfigurasi keamanan database menggunakan DCL (10%)
    3. Implementasi replikasi database (10%)
    4. Kualitas kode dan optimasi query (5%)

## 3. Dokumentasi (15% dari nilai project)
    1. Dokumentasi desain database (5%)
    2. Manual penggunaan sistem (5%)
    3. Dokumentasi konfigurasi keamanan dan replikasi (5%)

## 4. Presentasi (15% dari nilai project)
    1. Kemampuan menjelaskan sistem (5%)
    2. Kemampuan menjawab pertanyaan (5%)
    3. Kerjasama tim saat presentasi (5%)


# Penilaian Individu:
* Nilai akhir project akan dipengaruhi oleh kontribusi individual
* Setiap anggota harus mencantumkan bagian yang dikerjakan
* Penilaian peer review antar anggota kelompok
* Kemampuan individual saat presentasi dan tanya jawab
